# Abstract {.unnumbered}

[Abstract to be written last — 250 to 300 words. Cover, in this order: the problem (declining engagement with traditional loyalty programmes, fragmented databases, the trust deficit, and the failure of existing blockchain solutions to onboard real consumers); the solution approach (a Sui-based loyalty platform that uses zkLogin to derive blockchain addresses from Google Sign-In, sponsored transactions to remove all gas costs from the consumer journey, and Dynamic Object Fields to mutate on-chain NFTs without re-creating them); the result (a working multi-brand loyalty system deployed on Sui testnet with cryptographic transaction-digest evidence, a consumer progressive web app, a brand-operator portal, and 68 passing automated tests); and the contribution (the first publicly documented open-source implementation of a zkLogin-authenticated Dynamic NFT loyalty system on Sui, plus a critical reflection on whether blockchain materially adds value over a traditional database for this class of system).]
